# .frac.md — src/ui/sourceControl/components

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

Source Control 侧边视图里「文件列表怎么画」的 Svelte 5 组件：一个递归目录树，加四种叶子行（已暂存 / 未暂存 / 已拉取 / 冲突）和一个「超出上限」提示行。

本层只渲染，并把点击转发成「入队 Git 动作 / 打开文件 / 打开 diff」，不持有文件状态；树数据、`closed`、`conflictCounts` 都由上级 `../sourceControl.svelte` 传入。没有 `.ts` 文件。

## 2. 直属文件

- `treeComponent.svelte`：入口，递归渲染 `StatusRootTreeItem`，按 `fileType` 把叶子分派给下面四种行。目录行自带折叠、右键菜单和目录级按钮（staged 只有 Unstage，changed 有 Discard 与 Stage，pulled / conflicted 没有）；末尾放 `tooManyFilesComponent`。
- `fileComponent.svelte`：未暂存行。点击开 diff（二进制文件直接打开）；按钮：打开文件、Discard、Stage。
- `stagedFileComponent.svelte`：已暂存行，结构同上；diff 以 `HEAD` 为 A 侧（重命名取 `change.from`）；按钮：打开文件、Unstage。
- `pulledFileComponent.svelte`：拉取下来的远端变更行，只读：点击打开文件，从不开 diff，没有按钮。
- `conflictFileComponent.svelte`：冲突行。不收 `change`，只收 `path` / `count` / `manager`；唯一按钮 Mark resolved 调 `gitActions.stage`。`count` 三态：`undefined` 不标记，`0` 显示已解决，大于 0 显示冲突数。本层唯一带实质 scoped 样式的文件。
- `tooManyFilesComponent.svelte`：条目超过上限时显示「And N more files」，否则渲染空 `<main>`。

## 3. 子目录导航

无直属子目录。

## 4. 本层约束 / 约定 / 禁忌

- 会改仓库状态的点击一律 `plugin.promiseQueue.addTask(() => plugin.gitActions.xxx(...))`，不在组件里直接调 `gitManager` 的变更方法，也不绕开队列。
- 路径口径要分清：`path` 是 Git 侧路径（给 `gitActions.stage` 系列、`fileIsBinary`），`vaultPath` 是 vault 路径（给 `getAbstractFileByPath`、`aria-label`、`mayTriggerFileMenu`）；冲突行只拿到 `path`，靠 `manager.getRelativeVaultPath` 换算。例外：目录 Discard 传 `vaultPath`，文件 Discard 传整个 `change`。
- 渲染条目上限在 `treeComponent` 与 `tooManyFilesComponent` 各写死一份，改上限必须同步；它限制每层直接子节点，不是整棵树。
- `onMount` 里把过大的直接子目录置为折叠，只在该层挂载时跑：父目录折叠后再展开会重新挂载，覆盖用户手动展开的状态。
- 折叠约定与 history 相反：`closed[path]` 缺省为展开；`closed` 自最外层经 `bind:closed` 逐层下传，不要在子层另建副本。
- 叶子行图标由 `$effect` 里 `setIcon` 按 `data-icon` 填充，元素来自 `bind:this`；新增按钮要同时加 `data-icon` 和 `buttons[n]`。目录行按钮是手写内联 SVG，改图标要改 SVG。
- `conflictFileComponent` 没有 `onauxclick` / 悬停预览 / 右键菜单，辅助键点击会冒泡到外层目录 div 的 `onauxclick`。
- 不判断平台，没有 desktop / mobile 分支；文案是硬编码英文，无 i18n。

## 5. 什么时候需要下钻

- 加 / 改某类文件行的按钮或点击行为：读对应 `*FileComponent.svelte`，并追到 `plugin.gitActions`（动作）、`plugin.tools.openDiff`（diff 的 `aRef` / `bRef` 口径在那里）、`src/utils`（`mayTriggerFileMenu`、`getNewLeaf`、`hoverPreview`）。
- 改文件分组、排序、树的构造、`FileType` 取值、`conflictCounts` 的来源与刷新：不在本层，看 `../.frac.md`，以及 `src/types`、`GitManager` 的树构造方法。
- 新增一种文件状态区块：同时改 `treeComponent.svelte` 的 `fileType` 分派和目录按钮分支，并新增叶子组件。
