# .frac.md — src/ui/diff

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

两个 Obsidian `ItemView` 形式的 diff 视图，加一个给 CodeMirror 用的右键菜单扩展。两个视图都用 `DiffViewState`（`src/types`）作状态；本层不决定「选哪个视图、怎么打开」，也不负责注册。

## 2. 直属文件

- `diffView.ts`：`DiffView`，只读统一 diff。`refresh()` 取 `gitManager.getDiffString`，用 `diff2html` 渲染；结果为空时兜底（已跟踪无变化、合成「全部新增」、File not found）。监听 `obsidian-git:status-changed` 自动刷新。
- `splitDiffView.ts`：`SplitDiffView`，`@codemirror/merge` 左右分栏，加 `getSplitDiffTimeout`。左 a 侧只读；右 b 侧按 `bRef` 是工作区 / 暂存区 / 提交，仅工作区且文件存在时可编辑并防抖写回。刷新来自 `obsidian-git:status-changed`、定时器和 vault 事件。
  - `gitShow` 把 simple-git 的 `GitError`（不存在、索引未合并）折成空串或退到 stage 2。
  - `renderButtons` 在桌面端给每个 chunk 画 Stage / Unstage / Reset hunk。
- `contextMenu.ts`：`getSelectedText` 与 `diffContextMenu`（Cut / Copy / Paste / Select all 等），由 `splitDiffView` 挂到编辑器上。

## 3. 子目录导航

无直属子目录。

## 4. 本层约束 / 约定 / 禁忌

- ref 约定贯穿两个视图和调用方：`aRef` 为 `"HEAD"` / `""`（暂存区）/ 提交；`bRef` 为 `undefined`（工作区）/ `""`（暂存区）/ 提交。`undefined` 与 `""` 含义不同，不要用 `!bRef` 或 `??`。`aFile` / `bFile` 是仓库相对路径，进 vault 前要经 `gitManager.getRelativeVaultPath()`。
- 不继承 `FileView`：`.gitignore` 这类点文件没有 `TFile`，内容一律经 `vault.adapter` 读写 vault 相对路径。
- `SplitDiffView.refreshing` 是共用互斥标志，忙时新请求直接丢弃，不排队。`ignoreNextModification` 是一次性标志，写盘失败时会一直保留并吞掉下一次外部修改。
- hunk Stage / Unstage 在 mousedown 里直接 `applyPatch`，不经 `plugin.promiseQueue`、没有 `try/catch`，与 `AGENTS.md` 的串行化要求不一致；改它要考虑并发与失败出口。
- 桌面 / 移动差异靠 `instanceof SimpleGit`（hunk 控件、`gitShow` 的 `GitError` 兜底、`DiffView` 的「已跟踪无变化」兜底），所以两个文件都 import `SimpleGit`。
- 生命周期两边不同：`DiffView` 手动 `workspace.on` + `offref`（`gitViewRefreshRef` 只声明从未赋值）；`SplitDiffView` 用 `registerEvent`，定时器手动清理。

## 5. 什么时候需要下钻

- 改 diff 取数：`src/gitManager`；改 hunk 计算与 patch 生成：`src/editor/signs/`。
- 改 `DiffViewState` 或视图常量：`src/types`、`src/constants`；注册与刷新编排在 `src/main.ts`。
- 谁在什么条件下打开哪个视图：调用方，看 `../.frac.md` 与 `plugin.tools`。
