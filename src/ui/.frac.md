# .frac.md — src/ui

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

插件的整个界面层。视图有 History、Source Control、统一 / 分栏 diff、只读文件视图、同步状态视图（维护版新增），另有对话框与状态栏分支名。列表型视图（history、sourceControl）是「TS 外壳 + Svelte 5 根组件 + `components/`」，其余是纯 TS。

界面层不实现 Git：动作走 `plugin.promiseQueue` / `plugin.gitActions` / `plugin.tools`，读状态走 `plugin.gitManager` 与 `plugin.syncSupervisor`；视图注册、命令 ID 与事件触发方在 `src/main.ts`、`src/commands.ts`。

## 2. 直属文件

- `readOnlyFileView.ts`：`ReadOnlyFileView`，用 CodeMirror 只读显示某 ref 下的文件；状态 `ReadOnlyFileViewState`（`src/types`），入口是 `plugin.tools.openFileAtCommit`。不捕获 `show` 错误，仅首绘失败时在 `obsidian-git:head-change` 重试。
- `syncStatusView.ts`（维护版新增）：`SyncStatusView`，纯 TS 同步状态页，订阅 `plugin.syncSupervisor.onChange` 每次 `render()` 重建。
  - 展示中英双语的实时同步进度（阶段、百分比、手动排队提示）、问题说明（来自 `src/syncProblems.ts`）、冲突路径卡片与一键「备份冲突改动并以远端为准同步」按钮（调用 `plugin.gitActions.rescueConflictsAndSync`），以及最近事件记录与复制详情。由 `SyncSupervisor.openView()` 打开。

## 3. 子目录导航

- `diff/`：见 `diff/.frac.md`；统一 / 分栏 diff 视图和编辑器右键菜单。
- `history/`：见 `history/.frac.md`；History 侧栏及提交列表 `components/`。
- `modals/`：见 `modals/.frac.md`；输入、分支过滤排序、`OperationProgressModal` 进度框、`DeleteRepositoryModal` 删库模式框等弹窗。
- `sourceControl/`：见 `sourceControl/.frac.md`；Source Control 侧栏与文件树 `components/`。
- `statusBar/`：见 `statusBar/.frac.md`；`BranchStatusBar`，状态栏分支名。

## 4. 本层约束 / 约定 / 禁忌

- 两个 Svelte 视图（`HistoryView`、`GitView`）外壳同构：`onOpen` → `reload()` → `mount` 根组件并传 `plugin` 与 `view`，重载与关闭先 `unmount`。
- 读走 `plugin.gitManager`，变更走 `plugin.promiseQueue.addTask`（例外：`SplitDiffView` hunk 暂存直调 `applyPatch`）。
- 桌面 / 移动能力判断靠 `gitManager instanceof SimpleGit`，不假设桌面命令移动可用。
- workspace 监听事件（`obsidian-git:status-changed`、`obsidian-git:head-change`、`obsidian-git:repository-state-changed`）在 UI 外触发；UI 反向触发 `obsidian-git:refresh`，不自建轮询。
- 卸载与设置重载两条路径都要清理监听与定时器；新增出错路径走 `plugin.displayError` 或监督器问题状态，不静默吞错。
- 跨目录耦合：`settings.treeStructure` 被 history 与 sourceControl 共用；`MergeConflictModal` 描述 `src/editor/conflicts` 与 Source Control 的冲突操作。
- 除 `SyncStatusView` 中英双语外界面主文案为英文；全局样式在 `styles.css`（维护版用 `.git-maintained-*` 前缀）。

## 5. 什么时候需要下钻

- 改 History / Source Control / Diff / Modals：先读对应子目录 `.frac.md`；改冲突或同步界面须联动检查对应测试。
- 改同步状态页：`syncStatusView.ts`、`src/syncSupervisor.ts`、`src/syncProblems.ts` 与 `src/gitActions.ts`（`rescueConflictsAndSync`）。
- 新增视图 / 弹窗：常量在 `src/constants.ts`，类型在 `src/types.ts`，注册在 `src/main.ts`，命令在 `src/commands.ts`。
