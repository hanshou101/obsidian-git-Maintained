## 1. 本目录是什么

History 侧边视图里「一条提交怎么画」的三个 Svelte 5 组件：提交行（可折叠）→ 变更文件树（按目录折叠）或扁平文件列表 → 单个变更文件行。
全部使用 runes 写法（`$props` / `$state` / `$derived` / `$effect` / `$bindable`、`{@attach}`），根元素统一是 `<main>`，样式块为 `<style lang="scss">`。
本层不拥有提交列表、分页、加载状态，只接收一条 `LogEntry`，并通过 `view`（`HistoryView`，类型引自 `../historyView`）和 `plugin`（`ObsidianGit`）回调插件。
入口组件是 `logComponent.svelte`（本层其他文件不引用它，由上级使用）；没有任何 `.ts` 文件，没有对外导出的函数。
共用类型来自 `src/types`（`LogEntry`、`DiffFile`、`HistoryRootTreeItem`、`TreeItem`），工具函数来自 `src/utils`。

## 2. 直属文件

- `logComponent.svelte`：一条提交的折叠行。Props：`log: LogEntry`、`view: HistoryView`、`showTree: boolean`、`plugin: ObsidianGit`。
  - 标题行：`log.refs`（非空才渲染 `.git-ref`）、作者、日期、`log.message`。作者受 `plugin.settings.authorInHistoryView` 控制：`"full"` 全名，`"initials"` 取每个单词首字母大写，其余值（含 `"hide"`）不渲染；`log.author?.name` 为空也不渲染。日期仅在 `plugin.settings.dateInHistoryView` 为真时渲染，格式为 `plugin.settings.commitDateFormat`（obsidian 的 `moment`）。
  - tooltip 文本为「作者名 / 日期 / message / body」，既写进 `aria-label`，又由 `{@attach}` 调 `setTooltip(..., { placement: getTooltipSide(view.leaf), classes: ["obsidian-git-commit-tooltip"] })`。
  - `isCollapsed = $state(true)`（默认折叠），展开区用 `transition:slide|local` 150ms。展开后：`showTree` 为真渲染 `LogTreeComponent`（`hierarchy` 由 `plugin.gitManager.getTreeStructure(log.diff.files)` 派生，根节点 `title/path/vaultPath` 均为空串，`topLevel={true}`，`bind:closed`），否则按 `log.diff.files` 平铺 `LogFileComponent`。
  - 本组件持有该提交自己的 `closed: Record<string, boolean>`；折叠提交会销毁子树，但 `closed` 留在这里，再次展开时目录折叠状态保留。
- `logTreeComponent.svelte`：递归的目录树。Props：`hierarchy: HistoryRootTreeItem`、`plugin`、`view`、`topLevel?: boolean`（默认 false，只加到 `<main class:topLevel>`）、`closed`（`$bindable()`）。
  - 遍历 `hierarchy.children`：`entity.data` 有值是叶子，渲染 `LogFileComponent diff={entity.data}`；否则是目录，点击行 `fold()` 翻转 `closed[item.path]`（键是 `TreeItem.path`，不是 `vaultPath`），未折叠时递归渲染自身（`entity as HistoryRootTreeItem` 强转，文件首行有 `tslint:disable ts(2345)`）并 `bind:closed`。
  - 目录行 `aria-label={entity.vaultPath}`，显示 `entity.title`。`data-icon="folder"` 的 div 在本文件内没有任何 `setIcon` 调用。
- `logFileComponent.svelte`：单个变更文件行。Props：`diff: DiffFile`、`view: HistoryView`。
  - 主点击 `mainClick`：`fileIsBinary(diff.path)` 为真 → `open`（`vault.getAbstractFileByPath(diff.vaultPath)` 得到 `TFile` 才用 `getNewLeaf(app, event)?.openFile`，否则什么都不做，失败走 `plugin.displayError`）；否则 `showDiff` → `plugin.tools.openDiff({ event, aFile, aRef, bFile, bRef })`：`aFile = diff.fromPath ?? diff.path`（重命名取旧路径），`aRef` 是 `diff.hash` 加 `^`（父提交），`bFile = diff.path`，`bRef = diff.hash`。本组件不处理「根提交没有父提交」。
  - `onauxclick`：`event.button == 2`（右键）→ `mayTriggerFileMenu(app, event, diff.vaultPath, view.leaf, "git-history")`；其余辅助键（中键）→ `mainClick`。所有 handler 都 `stopPropagation`。
  - 行内两个图标按钮：`go-to-file`（`buttons[0]`，`fileOpenableInObsidian(diff.vaultPath, app)` 为真才显示，调 `open`）；`file-clock`（`buttons[1]`，要求 `diff.status !== "D" && !diff.binary && !fileIsBinary(diff.path)`，调 `plugin.tools.openFileAtCommit(diff.path, diff.hash)`）。右侧显示状态字母 `<span class="type" data-type={diff.status}>`，路径显示用 `getDisplayPath(diff.vaultPath)`。

## 4. 本层约束 / 约定 / 禁忌

- 折叠状态的默认值相反：提交行默认折叠（`isCollapsed = true`），目录默认展开（`closed[path]` 缺省 = undefined = 展开）。`closed` 自 `logComponent` 经 `bind:closed` 逐层下传，不要在子层另建副本。
- 图标靠 `$effect` 里 `setIcon(b, b.getAttr("data-icon")!)` 填充，对象是 `bind:this={buttons[i]}` 收集的元素。给 `logFileComponent` 新增图标按钮时，`data-icon` 和 `buttons[n]` 绑定缺一不可；`{#if}` 条件不满足时对应槽位为空（`if (b)` 已防御）。
- `logFileComponent` 里「打开」与「diff」的分流依据是 `fileIsBinary(diff.path)`（按路径判断），而 `file-clock` 按钮另外检查 `DiffFile` 上的 `binary` 字段；两者口径不同，改其一要想想另一处。
- 本层不判断平台，没有 desktop/mobile 分支；改它调用的 `plugin.gitManager.getTreeStructure`、`plugin.tools.openDiff` / `openFileAtCommit` 的语义时按 AGENTS.md 兼顾两个后端。异步失败要走 `displayError`（`open` / `openAtCommit` 已 `.catch`）。
- 组件里没有键盘事件处理，a11y 告警用 `svelte-ignore a11y_*` 注释压制，不是已解决。
- 本层 `<style>` 只有 `.nav-file-title`（`align-items`）和 `.nav-folder-title-content`（flex 居中）两条；`git-ref` / `git-author` / `git-date` / `git-tools` / `obsidian-git-commit-tooltip` 等类名在本层没有样式定义，改外观去根目录 `styles.css` 里搜。
- 类名沿用 Obsidian 文件浏览器的 `tree-item` / `nav-folder` / `nav-file` 体系，以便继承主题样式；不要随意改名。

## 5. 什么时候需要下钻

- 改提交行显示（作者缩写、日期、refs、tooltip）：看 `logComponent.svelte`，对应设置项 `authorInHistoryView` / `dateInHistoryView` / `commitDateFormat` 在 `src/setting/`。
- 改文件行点击、右键菜单、按钮：看 `logFileComponent.svelte`，并追到 `src/utils`（`fileIsBinary`、`getNewLeaf`、`mayTriggerFileMenu`、`fileOpenableInObsidian`）和 `plugin.tools`。
- 改目录树的构造方式（如何由 `log.diff.files` 生成层级）：不在本层，在 `plugin.gitManager.getTreeStructure` 的实现里。
- 提交列表如何获取、何时重绘、`showTree` 由谁决定：看上级 `../.frac.md`（`src/ui/history`）。
