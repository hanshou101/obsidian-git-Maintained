> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。

## 1. 本目录是什么

插件的 Git 能力层：抽象契约 `GitManager` 由两个互不相通的后端实现。
- 桌面：`SimpleGit`，驱动本机 `git`，认证走 `askpassServer.ts`。
- 移动：`IsomorphicGit`，用 `isomorphic-git`，文件系统经 `myAdapter.ts`，HTTP 经 `networkPolicy.ts`。

后端由 `src/main.ts` 选。调用方：`src/gitActions.ts`、命令、`src/ui/**`、`src/syncSupervisor.ts`，以及只能用 `SimpleGit`（`blame` / `show`）的 `src/editor/lineAuthor`、`src/editor/signs`。对外一律 vault 相对路径，仓库相对路径只在本目录内。

## 2. 直属文件

- `gitManager.ts`：抽象类 `GitManager` 与 `PullRecovery`；含状态、暂存、提交（`commitAll` 支持 glob）、同步、分支、log、路径转换与 `withGitOperation`。维护版新增中断 pull 恢复、`commitsAhead()` 与 `withRescueFolderOverride()` 默认实现，由后端覆写。
- `simpleGit.ts`：桌面后端，另导出 `zeroCommit`。含 `blame`、`applyPatch` 等桌面能力；askpass 脚本目录优先取 `manifest.dir`；支持删库清 `.git` 及工作区与索引协同操作。
- `isomorphicGit.ts`：移动后端，`pull` 永远是 merge。维护版新增：公开 `network`、`scopedStatus`、`commitsAhead`、拉取中断修复与冲突自动救援——配了 `rescueFolder` 时提取纯净本机版本（索引 stage-2 / 本地 blob，绝不抄冲突标记）另存并自动完成双亲合并；`ensureCleanPullWorktree` 仅检查受影响路径（仅多基回落全树校验），`getRemoteBranches` 改用标准 `.filter` 过滤 `HEAD`。
- `networkPolicy.ts`（维护版新增）：弱网策略，导出 `sendRequest`、`NetworkEnvironment`、`isNetworkFailureMessage`（`src/syncProblems.ts` 也用）；弱网模式关时透传 `requestUrl`。
- `myAdapter.ts`：isomorphic-git 的 `fs.promises` 适配器；非隐藏路径走 Vault API，隐藏路径走底层 adapter；`.git/index` 内存缓存、`saveAndClear()` 落盘；`readdir` 规整首斜杠以防 pruned fetch 产生双斜杠 ref 错误。
- `askpassServer.ts`：`AskpassServer`（仅桌面），本机 token 校验桥，弹出 `GeneralModal` 获取凭据。

## 4. 本层约束 / 约定 / 禁忌

- 新增 Git 操作：先改 `GitManager` 签名，再实现两端；仅桌面支持的能力调用方用 `instanceof SimpleGit` 守卫。
- 两端差异：`syncMethod`、`limitToVault`、`obsidian-git:head-change` 只在 `SimpleGit`；`getUnpushedCommits` 返回变化文件数，提交数用 `commitsAhead`。
- 自动提交 glob 两端匹配器不同（Git pathspec / JS 选择器），改语义需双端验证。
- 改 index 的 `git.*` 调用必须经 `wrapFS`，否则 `MyAdapter` 内存 index 不落盘。
- 拉取日志在 `checkout` 前写、挪分支后删；写工作区前先调 `syncSupervisor.expectWrites`。复位「等于历史版本」的挡路文件不受设置控制；救援局部改动或拉取冲突才需要 `rescueFolder`。
- `networkPolicy.ts` 的超时阈值须与 Phone sync 设置页和 `README.md` 保持一致。
- 冲突抛 `GitConflictError`、断网抛 `NoNetworkError`；凭据读自 `localStorage` / `gitServerPassword`，不进 `settings`。

## 5. 什么时候需要下钻

- 改 Git 契约或后端：`gitManager.ts` + 两端实现；结果类型见 `src/types.ts`。
- 改认证：`simpleGit.ts` + `askpassServer.ts`（桌面）、`isomorphicGit.ts` `getRepo()`（移动）。
- 改拉取修复、冲突自动/一键救援、弱网策略：`isomorphicGit.ts`、`networkPolicy.ts`、`myAdapter.ts`；对应测试在 `tests/gitManager/`。
