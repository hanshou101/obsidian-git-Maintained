# .frac.md — src/gitManager

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

插件的 Git 能力层：抽象契约 `GitManager` 由两个互不相通的后端实现。
- 桌面：`SimpleGit`，驱动本机 `git`，认证走 `askpassServer.ts`。
- 移动：`IsomorphicGit`，用 `isomorphic-git`，文件系统经 `myAdapter.ts`，HTTP 经 `networkPolicy.ts`。

后端由 `src/main.ts` 选。调用方：`src/gitActions.ts`、命令、`src/ui/**`、`src/syncSupervisor.ts`，以及只能用 `SimpleGit`（`blame` / `show`）的 `src/editor/lineAuthor`、`src/editor/signs`。对外一律 vault 相对路径，仓库相对路径只在本目录内。

## 2. 直属文件

- `gitManager.ts`：抽象类 `GitManager` 与接口 `PullRecovery`；契约含状态、暂存、提交（`commitAll` 带 glob `selection`）、同步、分支、log；共享 `withGitOperation`、路径转换。维护版新增默认实现 `recoverInterruptedPull()`、`commitsAhead()`，由后端覆写。
- `simpleGit.ts`：桌面后端，另导出 `zeroCommit`（line author 当「未提交」）。契约外独有 `blame`、`applyPatch` 等。askpass 脚本放插件目录，维护版取 `manifest.dir`（上游写死 `obsidian-git`）。
- `isomorphicGit.ts`：移动后端，`pull` 永远是 merge。维护版新增：公开字段 `network`、`scopedStatus`（只扫给定路径）、拉取中断修复、`commitsAhead`。
- `networkPolicy.ts`（维护版新增）：弱网策略，导出 `sendRequest`、`NetworkEnvironment`、`isNetworkFailureMessage`（`src/syncProblems.ts` 也用）；弱网模式关着时 `sendRequest` 就是 `requestUrl`。
- `myAdapter.ts`：给 isomorphic-git 的 `fs.promises`；非隐藏路径走 Vault API，隐藏路径走底层 adapter；`.git/index` 缓存在内存，`saveAndClear()` 才落盘。
- `askpassServer.ts`：`AskpassServer`（仅桌面），本机 token 校验服务，askpass 脚本经它弹 `GeneralModal` 取凭据。

## 3. 子目录导航

无直属子目录。

## 4. 本层约束 / 约定 / 禁忌

- 新增 Git 操作：先改 `GitManager` 签名，再实现两个后端；只有一端支持的能力不进契约，调用方用 `instanceof SimpleGit` 守卫。
- 两端差异：`syncMethod`、`limitToVault`、`obsidian-git:head-change` 事件只在 `SimpleGit`；`getUnpushedCommits` 两端返回的都是变化文件数，要提交数用 `commitsAhead`。
- 自动提交 glob 两端匹配器不同（Git pathspec / JS 选择器），改语义必须双端验证。
- 改 index 的 `git.*` 调用必须经 `wrapFS`，否则 `MyAdapter` 的内存 index 不落盘。
- 拉取日志在 `git.checkout` 前写、移动分支后删，顺序是契约；新增写工作区的步骤要先调 `plugin.syncSupervisor?.expectWrites`，否则被当成用户编辑。复位「内容等于历史版本」的本地文件不受设置控制，抄走其余本地改动才需要 `rescueFolder`。
- `networkPolicy.ts` 的超时数字也写在设置页 Phone sync 说明和 `README.md`，改要一起改。
- 冲突抛 `GitConflictError`、断网抛 `NoNetworkError`，不要吞掉；凭据读自 `plugin.localStorage` / `plugin.gitServerPassword`，不在 `plugin.settings`。

## 5. 什么时候需要下钻

- 改某个 Git 行为：先读 `gitManager.ts` 契约，再对照两个实现；结果类型在 `src/types`。
- 改认证：`simpleGit.ts` 的 `setGitInstance` + `askpassServer.ts`（桌面），`isomorphicGit.ts` 的 `getRepo()`（移动）；存储位置见 `src/setting/.frac.md`。
- 改提交范围：两个 `commitAll` / `selectAutoCommitFiles`，规则在 `src/autoCommitGlobs.ts`，手动提交带不带 `selection` 在 `src/gitActions.ts`。
- 改弱网策略或拉取中断修复：`networkPolicy.ts`、`isomorphicGit.ts` 的 `pull` / `recoverInterruptedPull` / `clearPullBlockers`；测试见 `tests/gitManager/.frac.md`，监督器 `src/syncSupervisor.ts`，用户文案 `src/syncProblems.ts`。
