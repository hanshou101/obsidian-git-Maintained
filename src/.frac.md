# .frac.md — src

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

插件源码总入口，由 Vite（根目录 `vite.config.mjs`）从 `main.ts` 打成根目录的 `main.js`。直属文件管插件生命周期、命令、Git 动作编排、自动化定时、手机同步监督、设置类型与默认值；Git 后端、编辑器集成、设置页和界面各在一个子目录。
- 后端二选一：`main.ts` 的 `useSimpleGit`（即 `Platform.isDesktopApp`）选桌面的 `SimpleGit` 或移动的 `IsomorphicGit`，见 `gitManager/.frac.md`。
- 维护版主要差异：插件 id 是 `git-maintained`；设置 `manualCommitUsesAutoCommitGlobs`；手机同步（`syncSupervisor.ts`、`syncProblems.ts`、拉取/冲突救援、非阻塞手动同步排队与状态监控）；分支过滤排序、Pull/Clone 实时进度框与两选项删库框；手机推送重传修复在 `patches/`。

## 2. 直属文件

**入口与 Git 动作编排**
- `main.ts`：默认导出 `ObsidianGit`（Plugin），也是 `main.js` 唯一导出（Vite 配置 `exports: "default"`）。`onload` → `init()` 建后端并检仓库，Git 就绪后启动自动化；`unloadPlugin()` + `init({ fromReload: true })` 重载设置；`displayError` / `handleConflict` 统一出错入口。
  - 维护版：官方插件启用时弹常驻通知后返回；`loadSettings` 无 `data.json` 时迁移官方设置；vault 四事件走 `onVaultChange`；启停 `syncSupervisor`，启动 `autoPullOnBoot` 纳入 `boot-pull` 监督路径。
- `gitActions.ts`：`GitActions`，全部面向用户的 Git 动作。公开方法包在 `runReadyGitAction` 与 `gitAction.ts` 结果类型里，核心逻辑在 `perform*`。commit-and-sync：提交 → 拉（移动端 merge）→ 推。
  - 手动提交在 `manualCommitUsesAutoCommitGlobs` 开时复用自动 glob 选择（手动已暂存仍提交）；解决冲突支持一键 `rescueConflictsAndSync()`（stage-2 提取纯净本地版、中止合并、拉取、提交备份并推送），且手动删除冲突文件或清掉冲突标记后同步即自动标为已解决。
  - 手动 `pull`（忽略 `disablePopups`）与 `clone` 使用 `OperationProgressModal` 展示实时进度；`deleteRepository` 使用 `DeleteRepositoryModal` 支持仅删 `.git` 或删 `.git` 及文件（保留 `.obsidian/`）并立即刷新状态；同步动作均向 `syncSupervisor` 汇报。
- `gitAction.ts`：`GitActionResult<T>`、`GitActionHost`、`runGitAction`：按错误类型分派 host（冲突、断网、用户取消记 cancelled），维护版支持 `observeError(error): boolean` 决定是否吞掉弹窗。
- `automaticsManager.ts`：自动 commit-and-sync / pull / push 定时器与停笔防抖提交；`autoSyncDelaySeconds` 覆盖自动等待时间，并与 `syncSupervisor` 协作避免吞掉手动同步。
- `autoCommitGlobs.ts`：解析 auto commit globs 生成匹配器与选择器，含 `includeGlobScope(globs)` 供移动后端收窄 `scopedStatus` 目录。
- `promiseQueue.ts`：`PromiseQueue`，Git 动作串行执行（`addTask(fn, onFinal)` 不回传 promise）。`coalesce.ts`：合并并发刷新调用。

**手机同步（维护版新增）**
- `syncSupervisor.ts`：`SyncSupervisor`（`plugin.syncSupervisor`）。始终记录同步历史、实时进度（阶段、百分比）、当前问题与联网状态（存本设备 localStorage），`managing`（`weakNetworkMode || syncOnLeave`）为真时执行重试、离开/回来调度。
  - 暴露 `snapshot()`、`onChange`、`openView()`、`noteVaultChange`、`onLeave` / `onReturn`、`requestSync(reason)`（支持在自动同步进行中排队追加一次手动同步及 `boot-pull`）；`inBackground` 跟随 Capacitor `pause`/`resume`，`updateKeepAwake()` 保持亮屏。
- `syncProblems.ts`：把同步错误归类（`classifySyncError` → `SyncProblem`：是否可自动重试、是否需人工处理、受阻/冲突文件列表），并输出中英文说明与操作指引（含冲突列表与一键救援提示）。

**命令、类型、常量**
- `commands.ts`：`addCommmands`（保留原拼写）注册全部命令（前缀 `git-maintained:*`）。含 `open-sync-status` 与 `rescue-conflicts-and-sync`；手动 `pull` / `fetch` / `push2` 经 `openQueuedProgressModal` 展示实时进度，手动同步请求交由 `syncSupervisor` 排队跟进。
- `types.ts`：`ObsidianGitSettings`、`declare module "obsidian"` 私有 API 补型、跨后端结果与状态类型、错误类（`GitConflictError`、`NoNetworkError`）。
- `constants.ts`：`DEFAULT_SETTINGS`（新设置默认值等于上游行为）、各视图 `*_VIEW_CONFIG`（含 `SYNC_STATUS_VIEW_CONFIG`）、默认路径与脚本名。

**其他**
- `statusBar.ts`（状态栏操作/进度/离线/合并态）、`tools.ts`（大文件检查、diff/历史打开、原始命令）、`openInGitHub.ts`、`utils.ts`、`pluginGlobalRef.ts`、`externalLibTypes.d.ts`。

## 3. 子目录导航

- `editor/`：见 `editor/.frac.md`；编辑器冲突块操作（全平台）、逐行 blame 与 gitsigns 标记（仅桌面 `SimpleGit`）。
- `gitManager/`：见 `gitManager/.frac.md`；`GitManager` 抽象契约、`SimpleGit` / `IsomorphicGit`、`MyAdapter`、askpass、弱网策略、拉取恢复与冲突自动救援。
- `setting/`：见 `setting/.frac.md`；设置页（含手动 glob、停笔等待、Phone sync）、localStorage、密钥读取与 `stockPlugin.ts`。
- `ui/`：见 `ui/.frac.md`；History / Source Control / diff / 只读视图、同步状态页、分支过滤与进度/删库对话框。

## 4. 本层约束 / 约定 / 禁忌

- 改 Git 语义须同时顾两个后端：先改 `gitManager/` 契约，再改两边实现；对外路径一律 vault 相对。
- 动工作区或仓库状态的动作统一经 `promiseQueue` 串行排队，手动同步请求交由 `syncSupervisor` 记录与跟进，避免与自动备份相互吞掉。
- 上游视图 type、workspace 事件（`obsidian-git:*`）、原有类名、命令 id 与设置字段名发布后保持兼容；维护版新增前缀 `git-maintained-`。
- 新设置必须在 `types.ts`、`constants.ts`、`setting/settings.ts` 同步增加，默认维持上游行为；源码改完须 `pnpm run build` 更新 `main.js` 一同提交。
- 手机同步开关与弹窗抑制边界：重试看 `weakNetworkMode`、离开/回来同步看 `syncOnLeave`、亮屏看 `keepAwakeWhileSyncing`；`expectWrites(repoPaths)` 在自动写盘前登记以防回声触发同步；同步历史只写本设备 localStorage，不落盘到 vault。
- `SyncSupervisor` 与 `syncProblems.ts` 文案须维持中英双语一致；匹配英文报错的正则修改必须与 `gitManager/isomorphicGit.ts` 联动。

- 改设置、界面、弹窗或编辑器：`setting/.frac.md`、`ui/.frac.md`、`editor/.frac.md`；改手机打包补丁：`patches/.frac.md`。
- 改手机同步与问题归类：`syncSupervisor.ts`、`syncProblems.ts` 及 `tests/syncSupervisor.test.ts`、`tests/syncProblems.test.ts`、`tests/gitManager/phoneSync.test.ts`。
