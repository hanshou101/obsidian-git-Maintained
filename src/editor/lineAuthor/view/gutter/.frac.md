## 1. 本目录是什么

Line Author（逐行 blame 侧栏）的 gutter 渲染层：把一份 blame 结果（`LineAuthoring`）里某个行区间翻译成一个 CodeMirror `GutterMarker`，负责文字格式化、按提交年龄上色、占位（等待结果 / 未提交 / 未跟踪），以及右键时从 DOM 反查被点中的 gutter。
不取 blame、不决定何时刷新：类型来自 `../../model.ts`，缓存与右键菜单在上一层 `view/`，功能能否启用见 `../../.frac.md`。

## 2. 直属文件

- `gutter.ts`：导出 `TextGutter`（固定文字的占位 marker）、`LineAuthoringGutter`（真正的 blame marker）、工厂 `lineAuthoringGutterMarker`。
  - 文字由提交 hash 前缀、作者、日期拼成，各段可隐藏；作者与 committer 不同时作者名后加 `*`。
  - 「假提交」（zero commit 即未提交改动，或等待结果）把全局最长已渲染文字的非空白字符换成 `+`（新改动，只留末尾几个）或 `%`（等待中，优先），再补齐到持久化的间距长度，避免宽度抖动。
  - 附带 tooltip 和右键菜单读的提交信息（`enrichCommitInfoForContextMenu`）。
- `coloring.ts`：`coloringBasedOnCommitAge`（按提交年龄在 `colorNew` 与 `colorOld` 间插值，暗 / 亮色模式不同）、`previewColor`（设置页色块预览）、`setTextColorCssBasedOnSetting`（把 `textColorCss` 写进 CSS 变量 `--obs-git-gutter-text`）。
- `commitChoice.ts`：`chooseNewestCommit`，在闭区间内选「最新」提交代表这个 gutter；zero commit 直接入选，其余比作者时间。
- `initial.ts`：blame 未返回时的占位：`initialSpacingGutter`（宽度取持久化的间距长度）、`initialLineAuthoringGutter`（waiting 状态 marker）、`adaptiveInitialColoredWaitingLineAuthoring`（单行伪 blame，颜色取此前渲染过的年龄）。
- `untrackedFile.ts`：`newUntrackedFileGutter`，用单行伪 blame（`zeroCommit`）渲染，效果与「新改动」相同。
- `gutterElementSearch.ts`：右键菜单 workaround。`editor-menu` 事件拿不到目标 gutter，所以记下最近一次 `mousedown` 的坐标，`findGutterElementUnderMouse` 在 `attachedGutterElements` 里按位置命中；待官方修复后可移除。

## 4. 本层约束 / 约定 / 禁忌

- 必须经工厂建 `LineAuthoringGutter`，不要直接 `new`（实例按设置与区间缓存）。`eq()` 只比 `key`、行区间、`options`，不比 settings 和 blame 内容：内容变了必须换 `key`，CodeMirror 才会重绘。
- `initialLineAuthoringGutter` 的结果不可缓存：颜色取自当时已渲染的年龄，每次都要重取。
- 行号 1-based：`hashPerLine` 下标 0 是占位，`startLine` / `endLine` 为闭区间；`"untracked"` 变体在类型上被排除，未跟踪文件走伪 blame。
- `chooseNewestCommit` 在区间内没有 hash 时返回 `undefined`（类型上被 `undefined!` 绕过），而 `computeDom` 会直接访问它。
- 全局状态（`gutterInstances`、`attachedGutterElements`、最长已渲染 gutter、已渲染年龄）在上一层 `view/cache.ts`，本层只读写不拥有；动渲染要同时想到它们的失效时机。
- `gutter.ts` 的假提交路径和 `initial.ts` 用 `pluginRef.plugin!` 取间距长度，插件实例未设置会抛错。
- `gutterElementSearch.ts` 的 `mousedown` 监听没有移除路径，「已注册」靠坐标哨兵值判断，首次点击前重复调用会重复注册。

## 5. 什么时候需要下钻

- 改 gutter 文字、宽度稳定、配色：读 `gutter.ts`、`coloring.ts`，同时看上级 `view/.frac.md`。
- 改设置项的渲染效果：设置类型在 `../../model.ts`，默认值与设置页不在本目录。
- 改右键菜单命中：`gutterElementSearch.ts` + 上级 `view/contextMenu.ts`。
