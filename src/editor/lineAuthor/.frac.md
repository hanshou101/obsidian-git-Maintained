# .frac.md — src/editor/lineAuthor

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

Line Author：在 Markdown 编辑器左侧显示逐行 `git blame`（短 hash / 作者 / 日期，按提交年龄着色）。本层管类型与 StateField、blame 的计算与缓存、事件与启停；gutter 渲染在 `view/`。
**仅桌面可用**：`isAvailableOnCurrentPlatform()` 要求 `useSimpleGit && Platform.isDesktopApp`，blame 只经 `SimpleGit` 取；移动端不激活。实例在 `plugin.editorIntegration.lineAuthoringFeature`。
数据流：Obsidian 事件 → `LineAuthorProvider.trackChanged` → `SimpleGit`（HEAD、文件 hash、`blame`）→ 按 `LineAuthoringId` 缓存 → `eventsPerFilePathSingleton` 通知订阅编辑器（`../control.ts`）→ `lineAuthorState` → `view/`。

## 2. 直属文件

- `lineAuthorIntegration.ts`：导出 `LineAuthoringFeature`，管启用 / 停用 / 刷新和 Obsidian 事件。
  - `file-open`、`active-leaf-change`、vault `modify` / `rename` 触发 `trackChanged`；`obsidian-git:head-change`、`css-change` 触发整体重载。
  - 扩展开关靠对同一个数组 push / remove 再 `workspace.updateOptions()`。
- `lineAuthorProvider.ts`：导出 `LineAuthorProvider`、扩展常量 `enabledLineAuthorInfoExtensions`，并 re-export `previewColor`。
  - `trackChanged` 以 HEAD 与文件 hash 为 key，未命中缓存才 `blame`；`destroy()` 清缓存并调 `clearViewCache()`。
- `model.ts`：类型 `LineAuthoring = Blame | "untracked"`、`LineAuthoringId`、`LineAuthorSettings`。
  - `lineAuthorState`：初值 `undefined`；带 effect 的事务整体替换，否则累计未保存改动，`compare` 只比 `key`。`laStateDigest` 供视图缓存键。
  - `latestSettings` 必须先经 `LineAuthoringFeature.onLoadPlugin()` 注入；`maxAgeInDaysFromSettings` 运行时依赖 `src/setting/settings`。

## 3. 子目录导航

- `view/`：见 `view/.frac.md`；把 `lineAuthorState` 渲染成 gutter（区间装配、视图缓存、右键菜单），`gutter/` 管单个 marker 的文字、配色、占位。

## 4. 本层约束 / 约定 / 禁忌

- 刷新是重载式：HEAD、主题、设置变化都先 `deactivateFeature()` 再 `activateFeature()`，`lineAuthorings` 与视图缓存全丢；`lineAuthorings` 无淘汰策略。
- `lineAuthorState.update` 无 effect 时原地修改并返回同一对象，而 `compare` 只看 `key`：依赖未保存改动的缓存必须用 `laStateDigest`。
- 没有时间戳：旧的 blame 结果晚到会覆盖新的。
- vault `modify` / `rename` 处理器不 catch `trackChanged` 抛出的错，失败即未处理的 rejection。
- `deactivateCodeMirrorExtensions` 边遍历边 `.remove` 同一数组，只有一个扩展时才安全。

## 5. 什么时候需要下钻

- 改 gutter 显示、配色、缓存、右键菜单：读 `view/.frac.md`；改订阅者怎么把结果送进编辑器：`../.frac.md` 与 `../control.ts`。
- 改何时重算 / 刷新：读 `lineAuthorIntegration.ts` 的事件与 `lineAuthorProvider.ts`；blame 本身在 `src/gitManager/simpleGit.ts`。
- 改 `LineAuthorSettings` 字段：同时改 `model.ts`、`src/constants` 的 `DEFAULT_SETTINGS.lineAuthor`、`src/setting/settings.ts` 和 `view/contextMenu.ts`。
