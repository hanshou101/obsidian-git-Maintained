## 1. 本目录是什么

插件的设置界面与「设置之外的持久化」，外加维护版接手官方插件的逻辑（`stockPlugin.ts`）。前三个文件对应三种存放位置：
- 插件设置（`plugin.settings`，类型 `ObsidianGitSettings` 在 `src/types`，默认值 `DEFAULT_SETTINGS` 在 `src/constants`，持久化由 `src/main.ts` 的 `saveSettings()` 等负责）→ 设置页 UI 在 `settings.ts`。
- 本设备 + 本 vault 的状态 → `localStorageSettings.ts`（`plugin.localStorage`，基于 `app.loadLocalStorage` / `saveLocalStorage`；设置页对「Disable on this device」的说明是「This setting is not synced」）。
- Git 服务器密码（移动端 HTTP 认证）→ `gitServerPassword.ts`（`plugin.gitServerPassword`，基于 Obsidian `app.secretStorage`，设置里只存 secret 的 id）。
本目录不实现 Git 操作：除「仓库作者」两项会调用 `gitManager.getConfig` / `gitActions.setGitConfig` 外，其余都是通过 `plugin.*` 触发重载（`automaticsManager`、`editorIntegration`、`changeBasePath`、`changeGitPath`、`reloadGitManager`、`refresh` 等）。`src/gitManager/**` 读取这里的 `localStorage` / `gitServerPassword`，`src/editor/lineAuthor/model.ts` 反向依赖这里导出的 `parseColoringMaxAgeDuration`。

## 2. 直属文件

- `settings.ts`：导出 `ObsidianGitSettingsTab`（`PluginSettingTab`，实例即 `plugin.settingsTab`）、`pickColor`、`parseColoringMaxAgeDuration`。用 Obsidian 的声明式设置 API：`getSettingDefinitions()` 返回页面树（Automatic / Commit / Sync / Editor / Views / Interface / Identity / Advanced + Support 分组），控件用 `key` 绑定，读写分别走 `getControlValue(key)` 与 `setControlValue(key, value)`；少数行用 `render: (setting) => …` 自绘。
  - 绑定规则（`resolveControl`）：`hunks.` 前缀的 key 读写 `settings.hunks.*`，其余读写 `settings.*`；`INVERTED_CONTROLS` 里的两个界面键是存储键的取反（`showInformationalNotifications` ↔ `disablePopups`，`showNoChangesNotifications` ↔ `disablePopupsForNoChanges`）。`setControlValue` 的特例：`basePath` 不直接赋值而是 `plugin.changeBasePath(path)` 后返回；`autoCommitMessage` 置空会回退默认值；其余统一 `target[field] = value` → `saveSettings()`，再按 key 触发副作用——`AUTOMATIC_RELOADS` 里的 key 调用 `automaticsManager.reload(...)`（`differentIntervalCommitAndPush` → commit + push；`autoBackupAfterFileChange` / `setLastSaveToLastCommit` / `autoSaveInterval` → commit；`autoPushInterval` → push；`autoPullInterval` → pull）；`hunks.*` → `editorIntegration.refreshSignsSettings()`；`authorInHistoryView` / `dateInHistoryView` / `commitDateFormat` → 重载已打开的 History 视图；`limitToVault` → `plugin.refresh()`；`refreshSourceControlTimer` → `setRefreshDebouncer()`。**新增布尔 / 下拉设置，若需要副作用，就在 `setControlValue` 或 `AUTOMATIC_RELOADS` 里加。**
  - 显隐谓词：`ready`（`plugin.gitReady`）、`desktop`（`gitManager instanceof SimpleGit`）、`mobile`（`instanceof IsomorphicGit`）。桌面独有：Merge strategy（`syncMethod`）、`rebaseAutoStash`、`squashCommitsBeforePush`、`updateSubmodules`、`submoduleRecurseCheckout`、自定义 git 路径 / 环境变量 / PATH / 重载按钮、`diffStyle`、`diffTimeout`、`commitMessageScript`、整个 Editor 页；移动独有：服务器用户名与密码（`SecretComponent` 绑定 `settings.gitServerPasswordSecret`）。
  - **维护版新增：Automatic 页里的开关「Use these globs for manual commits too」**，绑定设置 `manualCommitUsesAutoCommitGlobs`（默认 `false`，默认值与类型分别在 `src/constants`、`src/types`）。位置在「Globs for auto …」文本框（`autoCommitGlobs`）之后、「Specify custom commit message on auto …」之前，用通用的 `this.toggle(...)` 定义，没有额外副作用。开启后手动提交（Commit all changes、commit-and-sync 等）也只暂存自动提交 glob 选中的文件，用户自己暂存的文件照样提交；实现逻辑在 `src/gitActions.ts`，本文件只负责这个设置项的展示与保存。同页相关项：`autoCommitGlobMode`（exclude / include；include 且列表为空时只提交已暂存文件）、`autoCommitGlobs`（每行一个仓库相对 Git glob，`/` 为分隔符）。说明文字写明 glob 在自动暂存时优先于 `limitToVault`。
  - Line author 设置：`configureLineAuthorShowStatus(show)`（写 `lineAuthor.show` 并 `activateLineAuthoring()` / `deactiveLineAuthoring()`）、`lineAuthorSettingHandler(key, value)`（**把 `value` 原样写入 `settings.lineAuthor[key]`，保存，再 `lineAuthoringFeature.refreshLineAuthorViews()`，不做取反**；gutter 右键菜单也调用它）、`beforeSaveSettings()`（`authorDisplay` / `dateTimeFormatOptions` 非 `hide` 时把当前值记到 `lastShown*`，供右键菜单恢复显示；按名称应由保存设置的流程调用，调用点在本目录之外）、`renderLineAuthorSettings(containerEl)`（命令式自绘整页，经 `LineAuthorSettingsPage`（`SettingPage`）挂在 Editor 页下，re-render 用 80ms 防抖的 `refreshLineAuthorPage`，`hide()` 时 `cancelLineAuthorRefresh()`）。颜色预览用 `previewColor`（来自 `lineAuthorProvider` 的 re-export）。`parseColoringMaxAgeDuration("1y")` 把字符串拼成 ISO 8601 `P…` 交给 moment，要求有效且 ≥ 1 天；`coloringMaxAge` 输入非法时不会保存。
  - 其它行为：Identity 页用 `gitManager.getConfig(key, "local" | "global")` / `gitActions.setGitConfig` 读写仓库的 `user.name` / `user.email`（只有 `SimpleGit` 才取 global 作 placeholder）；「Disable on this device」写 `localStorage.pluginDisabled` 并 `unloadPlugin()` / `init({ fromReload: true })`；「Copy debug information」把完整 `settings` 序列化进剪贴板（可能含敏感信息）。
- `localStorageSettings.ts`：`LocalStorageSettings`，所有键前缀 `manifest.id + ":"`（维护版的 id 是 `git-maintained`，所以和官方版的 `obsidian-git:` 各存各的）。维护版加了 `importFrom(pluginId)`：把 `password`、`username`、`hostname`、`gitPath`、`PATHPaths`、`envVars`、`lastAutoPull` / `lastAutoBackup` / `lastAutoPush` 从 `<pluginId>:` 抄过来，只抄自己还没有值的键；`pluginDisabled`、`pausedAutomatics`、`gutterSpacingFallbackLength` 不抄。`migrate()` 把 `password` / `hostname` / `lastAutoPull` / `lastAutoBackup` / `lastAutoPush` / `gitPath` / `pluginDisabled` 从旧的 `window.localStorage` 搬到 `app.saveLocalStorage`（之后新增的键不在迁移列表里）。读写项：旧版明文密码（`get/set/clearLegacyPassword`）、`username`、`hostname`、`lastAutoPull` / `lastAutoBackup` / `lastAutoPush`（时间戳字符串）、`gitPath`、`PATHPaths`（`string[]`，以 `:` 连接存储）、`envVars`（`KEY=VALUE` 的 JSON 数组）、`pluginDisabled`、`pausedAutomatics`（为真时不应启动新的定时器）、`gutterSpacingFallbackLength`（line author gutter 的回退宽度，默认 5）。
- `gitServerPassword.ts`：`GitServerPassword`。`get()` 按 `settings.gitServerPasswordSecret` 从 `secretStorage` 取密码（未选择返回 `null`）；`set(value)` 在未选 secret 时从 `obsidian-git-password` 起避开已被占用的 id（`-2`、`-3`…）新建，并把 id 写回 settings（保存失败会回滚 id）；`migrateLegacy()` 把旧版 `localStorage` 明文密码迁入 secretStorage（已有可用 secret 优先于旧值），然后清掉旧值。`IsomorphicGit` 的 `onAuth` / `onAuthFailure` 是它的使用方。默认 secret 名维持上游的 `obsidian-git-password`。
- `stockPlugin.ts`（维护版新增）：`STOCK_PLUGIN_ID = "obsidian-git"` 与 `StockPlugin`（`plugin.stockPlugin`）。`isEnabled()`：自己的 id 不是 `obsidian-git`，且私有 API `app.plugins.enabledPlugins`（类型补在 `src/types` 的 `declare module "obsidian"`）含 `obsidian-git`。`importSettings()`：读 `${configDir}/plugins/obsidian-git/data.json`（经 `vault.adapter`）；文件不存在、不是 JSON 对象就返回 `null`（JSON 解析失败另记 `plugin.log`）；是对象就先 `localStorage.importFrom("obsidian-git")` 再返回它。调用方都在 `src/main.ts`：`onload` 开头 `isEnabled()` 为真就弹常驻通知并直接返回；`loadSettings` 在自己没有 `data.json` 时调用 `importSettings()`，拿到就以它为准合并默认值、立刻 `saveData`、弹通知。

## 4. 本层约束 / 约定 / 禁忌

- 新增设置项的完整落点：`ObsidianGitSettings`（`src/types`）+ `DEFAULT_SETTINGS`（`src/constants`）+ 本目录 `getSettingDefinitions()` 里的定义；需要副作用时再改 `setControlValue` / `AUTOMATIC_RELOADS`。`manualCommitUsesAutoCommitGlobs` 就是按这个模式接入的。
- 接手官方插件只在「自己没有 `data.json`」的那次启动发生，而且以官方 `data.json` 存在为前提；之后两边互不影响。官方插件启用时维护版整个不启动（两边注册同样的视图类型，也会同时同步同一个仓库），不要改成「两个都跑」。
- 现有的存放划分：每设备不同的路径 / 环境（git 路径、PATH、环境变量）、用户名、定时器时间戳、`pluginDisabled`、`pausedAutomatics`、gutter 宽度放在 `LocalStorageSettings`，不进 `plugin.settings`；密码走 `secretStorage`，`plugin.settings` 里只保存 secret 的 id（`gitServerPasswordSecret`）。新增设备相关状态沿用这个划分。
- 界面键与存储键不总是同名（取反的 `INVERTED_CONTROLS`、`hunks.` 前缀、自绘的「Push on commit-and-sync」直接写 `disablePush` 取反）；改键名时要同时看 `resolveControl` 和各处 `render`。
- `lineAuthorSettingHandler` 的契约是「调用方传新值」。`src/editor/lineAuthor/view/contextMenu.ts` 的 `showCommitHash` 分支传的是当前值而不是取反值，[推测] 点击该菜单项不会切换显示（`authorDisplay` / `dateTimeFormatOptions` 分支传的是目标值，没问题）。
- `renderLineAuthorSettings` 里 `!…lineAuthoringFeature.isAvailableOnCurrentPlatform()` 判断的是一个对象（`{ available, gitManager }`），恒为真值，所以「Only available on desktop currently.」永远不会出现；目前被 Editor 页的 `desktop()` 显隐谓词掩盖。
- `LocalStorageSettings.getPATHPaths()` 以 `:` 拆分，含盘符冒号的 Windows 路径（如 `C:\Program Files\Git\bin`）会被拆碎。
- 与 `limitToVault`：设置页文案说明「Configured auto commit globs take precedence for automatic staging」，而 `SimpleGit.commitAll` 在有 `selection` 时不再附加 vault pathspec；[推测] 开启 `manualCommitUsesAutoCommitGlobs` 后手动提交也是 glob 优先，对应文案目前只写了「automatic」。
- `plugin.localStorage` / `plugin.gitServerPassword` 是在 `gitManager` 里被直接调用的：`SimpleGit` 读 `getGitPath` / `getPATHPaths` / `getEnvVars`，`GitManager.formatCommitMessage` 读 `getHostname`，`IsomorphicGit` 读 `getUsername` 与 `gitServerPassword.get()`。改方法名或存储格式要同步 `src/gitManager`。

## 5. 什么时候需要下钻

- 加 / 改设置项或页面结构：读 `settings.ts` 的 `getSettingDefinitions()` 与 `setControlValue`，并确认 `src/types`、`src/constants` 中的类型与默认值。
- 改自动提交 glob 或 `manualCommitUsesAutoCommitGlobs` 的语义：设置项在这里，选择与提交逻辑看 `src/gitActions.ts`、`src/autoCommitGlobs.ts` 与 `src/gitManager/.frac.md`。
- 改 line author 设置或右键菜单联动：读 `settings.ts` 的 `lineAuthorSettingHandler` / `renderLineAuthorSettings` 与 `src/editor/lineAuthor/.frac.md`。
- 改凭据 / 设备级配置的存取：读 `localStorageSettings.ts`、`gitServerPassword.ts`，以及 `src/gitManager/.frac.md` 里的认证部分。
