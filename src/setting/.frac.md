# .frac.md — src/setting

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

设置界面、「设置之外的持久化」，以及维护版接手官方插件的逻辑。三种存放各一个文件：`plugin.settings` → `settings.ts` 的设置页；本设备状态 → `localStorageSettings.ts`；Git 服务器密码 → `gitServerPassword.ts`（`secretStorage`）。不实现 Git 操作；`src/gitManager/**` 直接调两个存储的方法。

## 2. 直属文件

- `settings.ts`：`ObsidianGitSettingsTab`、`parseColoringMaxAgeDuration`。声明式：`getSettingDefinitions()` 返回页面树，读写走 `getControlValue` / `setControlValue`（`resolveControl` 把界面键映到存储键），副作用在 `setControlValue` 与 `AUTOMATIC_RELOADS`。
  - 维护版新增：Automatic 页的 `manualCommitUsesAutoCommitGlobs`、`autoSyncDelaySeconds`，以及 Phone sync 页（`weakNetworkMode`、`syncOnLeave` 等四个设置和同步状态入口）；Phone sync 的设置只保存，由 `SyncSupervisor` / `IsomorphicGit` 读取时生效。
  - `lineAuthorSettingHandler(key, value)` 原样写入 `settings.lineAuthor`，不取反（gutter 右键菜单也调它）。
- `localStorageSettings.ts`：`LocalStorageSettings`，键前缀 `manifest.id + ":"`（维护版与官方版各存各的）。存每设备的 git 路径 / PATH / 环境变量、用户名、定时器时间戳等。维护版新增 `importFrom(pluginId)`（抄官方版自己没有的键）、`getSyncLog` / `setSyncLog`（同步历史，不放 vault 以免被提交）。
- `gitServerPassword.ts`：`GitServerPassword`，按 `settings.gitServerPasswordSecret` 在 `secretStorage` 存取密码，设置里只存 id；`migrateLegacy()` 迁旧明文密码。
- `stockPlugin.ts`（维护版新增）：`StockPlugin`，`isEnabled()` 判断官方插件是否启用，`importSettings()` 读官方 `data.json`；调用方在 `src/main.ts`。

## 3. 子目录导航

无直属子目录。

## 4. 本层约束 / 约定 / 禁忌

- 新增设置项三处都要加：`src/types` 的 `ObsidianGitSettings`、`src/constants` 的 `DEFAULT_SETTINGS`、`getSettingDefinitions()`。界面键与存储键不总同名（`hunks.` 前缀、`INVERTED_CONTROLS` 取反），改键名要看 `resolveControl` 和自绘的 `render`。
- 设备相关状态进 `LocalStorageSettings`，不进 `plugin.settings`；`syncLog` 不进 vault。改存储方法名或格式要同步 `src/gitManager`。
- 官方插件启用时维护版整个不启动（会同步同一个仓库），不要改成两个都跑；接手只在自己没有 `data.json` 时发生。
- Phone sync 说明写死了超时 / 重试 / 亮屏的数字（来自 `networkPolicy.ts`、`syncSupervisor.ts`），`README.md` 与 `src/syncProblems.ts` 也有，改常量要同步。
- `getPATHPaths()` 以 `:` 拆分，含盘符冒号的 Windows 路径会被拆碎。

## 5. 什么时候需要下钻

- 加 / 改设置项：`settings.ts` 的 `getSettingDefinitions()` 与 `setControlValue`。
- 改 glob 提交或 Phone sync 的行为：看 `src/gitActions.ts`、`src/syncSupervisor.ts`、`src/gitManager/.frac.md`。
- 改 line author 设置或凭据存取：分别看 `src/editor/lineAuthor/.frac.md`、`src/gitManager/.frac.md` 的认证部分。
