## 1. 本目录是什么

仓库根目录下的界面截图目录：只放插件四块主要界面的 PNG，沿用上游，没有文本、代码或子目录。它不是 `docs/assets/`（用户文档页面嵌入的图），也不属于发布产物（发布的只有 `main.js`、`manifest.json`、`styles.css`）。
根目录 `README.md` 的界面预览用的是上游仓库里同名文件的 raw 链接，不是本目录的文件：改这里的图不会改变 README 的显示。

## 2. 直属文件

- `source-view.png`：Source Control 视图。顶部工具栏图标、提交信息输入框、"Staged Changes" 与 "Changes" 两组、树形目录、文件状态字母（M、U、D）及每行的暂存/放弃按钮。
- `history-view.png`：History 视图。顶部是 `HEAD → master`，提交列表按时间倒序，提交可展开出变更文件及状态（A、M）。
- `diff-view.png`：并排（split）diff 视图。左侧红色标出删除、右侧绿色标出新增，中间每个 hunk 有暂存（`+`）与撤销按钮。
- `signs.png`：编辑器行号旁的 gutter 变更标记。黄条表示修改、绿条表示新增、红色短横表示删除。

## 4. 本层约束 / 约定 / 禁忌

- 界面截图不是代码生成的：没有脚本或源文件可以重新生成，界面改版后只能手工重新截图并保持文件名不变。
- 截图拍摄于较早的版本，与当前界面在细节上可能不一致（例如 History 里的提交时间），不能当作当前界面的权威依据。
- 不要和 `docs/assets/` 混放：文档页面引用的是那边的文件，改这里的文件名不影响文档页面，反之亦然。
