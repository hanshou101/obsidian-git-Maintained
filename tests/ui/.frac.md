## 1. 本目录是什么

`src/ui/`（source-control、history、diff、modal、status-bar 等界面代码）的测试目录，位于 `tests/` 之下，按源码子目录镜像。本目录自身没有直属文件，目前只有 `diff/` 一个子目录。
`obsidian` 的界面基类（`Modal`、`ItemView` 等）在 stub 里都是空类，所以这里的测试避开真实 UI 渲染：只测不依赖 DOM 的逻辑，并通过绕过构造函数的方式构造视图对象。

## 2. 直属文件

无直属文件。

## 3. 子目录导航

- `diff/`：见 `diff/.frac.md`；`src/ui/diff/splitDiffView` 的测试：`getSplitDiffTimeout` 的超时换算、`SplitDiffView.gitShow` 在冲突/已暂存状态下读哪个 index 阶段（真实 git 仓库）、以及视图刷新失败后 `refreshing` 标志的复位。

## 4. 本层约束 / 约定 / 禁忌

- 本目录没有自己的 fixture 或 mock：需要真实仓库时复用 `tests/helpers/`（`withCleanup`、`gitRepo`、`simpleGit`），见 `diff/.frac.md` 中的用法。
- 视图对象用 `Object.create(View.prototype)` + `Object.assign(...)` 注入字段来构造，而不是 `new`；因此被测方法读取的每个 `this.*` 成员都要在用例里显式提供。
- `src/ui/` 里的 Svelte 组件、其他 modal / 状态栏代码目前在本目录没有对应测试（只有 `diff/`）；弹窗相关行为是在 `tests/gitManager/askpass.test.ts` 里通过 `vi.mock` 整模块替换的。

## 5. 什么时候需要下钻

- 改 `src/ui/diff/` 下的 split diff 视图：读 `diff/.frac.md`。
- 要给 `src/ui/` 其他部分补测试：先读 `tests/stubs/.frac.md` 了解 `obsidian` 替身的边界，再读 `tests/helpers/.frac.md` 选择 fixture，然后在本目录下按源码路径新建镜像子目录。
