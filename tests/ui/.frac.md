> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

`src/ui/`（source control、history、diff、modal、状态栏等界面代码）的测试目录，位于 `tests/` 之下，按源码子目录镜像。本目录没有直属文件，目前只有 `diff/` 一个子目录；`src/ui/` 的其余部分没有对应测试。
`obsidian` 的界面基类（`Modal`、`ItemView` 等）在 `tests/stubs/obsidian.ts` 里都是空类，所以这里只测不依赖 DOM 的逻辑，视图对象绕过构造函数构造。

## 2. 直属文件

无直属文件。

## 3. 子目录导航

- `diff/`：见 `diff/.frac.md`；`SplitDiffView` 的 `gitShow`（真实 git 仓库里冲突态读哪个 index 阶段）、超时换算、视图刷新失败后 `refreshing` 的复位。

## 4. 本层约束 / 约定 / 禁忌

- 没有自己的 fixture 或 mock：需要真实仓库时复用 `tests/helpers/`（`cleanup`、`gitRepo`、`simpleGit`），用法见 `diff/.frac.md`。
- 视图对象用 `Object.create(View.prototype)` 加 `Object.assign(...)` 注入字段，不 `new`；被测方法读取的每个 `this.*` 成员都要在用例里显式提供。
- 弹窗相关行为不在这里测：`tests/gitManager/askpass.test.ts` 用 `vi.mock` 整模块替换 `generalModal`。

## 5. 什么时候需要下钻

- 改 `src/ui/diff/` 的 split diff 视图：读 `diff/.frac.md`。
- 给 `src/ui/` 其他部分补测试：先读 `tests/stubs/.frac.md` 了解 `obsidian` 替身的边界，再读 `tests/helpers/.frac.md` 选 fixture，然后在本目录下按源码路径新建镜像子目录。
