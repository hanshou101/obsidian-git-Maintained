# .frac.md — tests/ui

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

`src/ui/`（source control、history、diff、modal、状态栏等界面代码）的测试目录，位于 `tests/` 之下，按源码子目录镜像。包含对输入弹窗纯筛选/排序逻辑的直属测试，以及 `diff/` 子目录。
`obsidian` 的界面基类在 `tests/stubs/obsidian.ts` 里保持最小实现，所以这里主要测不依赖完整客户端渲染的 UI 逻辑与纯辅助函数。

## 2. 直属文件

- `generalModal.test.ts`：绕过完整 DOM 与 Obsidian 视图树，测 `GeneralModal` 的大小写无关子串过滤、排序规则（精确或 `/<query>` 后缀 → 前缀 → 较短优先）与 `limit = 500` 上限，不改源码结构，只检查导出或挂载后的排序结果。

## 3. 子目录导航

- `diff/`：见 `diff/.frac.md`；`SplitDiffView` 的 `gitShow`（真实 git 仓库里冲突态读哪个 index 阶段）、超时换算、视图刷新失败后 `refreshing` 的复位。

## 4. 本层约束 / 约定 / 禁忌

- 没有自己的 fixture 或 mock：需要真实仓库时复用 `tests/helpers/`（`cleanup`、`gitRepo`、`simpleGit`），用法见 `diff/.frac.md`。
- 视图 / 弹窗对象按需使用轻量属性注入或直接测导出纯逻辑；需要时提供最小假元素对象，不在全局 `setup.ts` 引入重型 DOM 模拟。
- Askpass 等集成弹窗测试仍在 `tests/gitManager/askpass.test.ts` 中通过 `vi.mock` 替换 `generalModal`。

## 5. 什么时候需要下钻

- 改 `GeneralModal` 候选项过滤、排序优先级或 `limit` 上限：看 `generalModal.test.ts` 与 `src/ui/modals/generalModal.ts`。
- 改 `src/ui/diff/` 的 split diff 视图：读 `diff/.frac.md`。
- 给 `src/ui/` 其他部分补测试：先读 `tests/stubs/.frac.md` 与 `tests/helpers/.frac.md`，再按源码路径建测试文件。
