# .frac.md — tests/gitManager

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

`src/gitManager/`、`GitActions` 与 askpass 凭据桥的集成测试，位于 `tests/` 之下。用例大多跑在真实临时 git 仓库上、不 mock git：桌面 `SimpleGit`、移动 `IsomorphicGit`、两端共用契约，以及维护版拉取恢复、冲突救援与手机同步。

## 2. 直属文件

**两个后端的行为**
- `gitManager.test.ts`：后端无关的契约测试（harness 在 `helpers/gitManagerHarness`）。覆盖 status / stage / commit（含 amend）、glob 选择、`manualCommitUsesAutoCommitGlobs`、detached HEAD、合并冲突流与 `GitActions.commit` / `commitAndSync`。
- `simpleGit.test.ts`：只测 `SimpleGit`：`limitToVault` 范围、commit、pull / push、branchInfo、fetch / checkout、进度事件映射、`squashAllUnpushedCommits`、`show`。
- `isomorphicGit.test.ts`：只测 `IsomorphicGit`：pull / merge 冲突态、push 结果、`status()` 与局部冲突物化（受影响路径拦下未提交冲突同时保留无关脏文件）；远端用 `update-ref` + `reset --hard` 模拟。

**维护版新增**
- `isomorphicGitPushAfterMerge.test.ts`：守护 isomorphic-git 补丁（merge 后 push 经真实 `git http-backend` 只传新对象）；测 `index.cjs` 与 `index.js`。
- `pullRecovery.test.ts`：`IsomorphicGit` 拉取恢复：半截 checkout 经日志补做、挡路改动与拉取冲突自动写入 `rescueFolder` 并完成纯净双亲合并（绝不抄写冲突标记）。
- `phoneSync.test.ts`：真实 `GitActions` + `SyncSupervisor` + `IsomorphicGit` 联动（含 HTTP 后端）：离开仅扫收件箱、弱网重试、`commitsAhead`、清理冲突标记或删除冲突文件后自动解决冲突、一键 stage-2 救援同步，以及 `updateUpstreamBranch` 与 pruned fetch。
- `networkPolicy.test.ts`：`networkPolicy.ts` 纯函数测试（注入环境、fake timers）：离线、超时、读重试、push 不重试、`redactUrl`。

**凭据桥**
- `askpass.test.ts`：`AskpassServer` 本机 HTTP 桥与 `ASK_PASS_SCRIPT` 端到端；脚本装入 `manifest.dir` 并写入 `.git/info/exclude`。

## 3. 子目录导航

无直属子目录。

## 4. 本层约束 / 约定 / 禁忌

- 环境依赖：PATH 须有 `git`（`git http-backend`、POSIX `sh`）。默认分支约定 `main` / `origin/main`（由 `helpers/gitRepo` 保证）。
- 仓库必须经 `withCleanup(...)` 或 `cleanup()` 回收，防临时目录泄漏。
- manager 层不弹错：失败只抛出，断言 `plugin.displayError` 未调用；`setPluginState` 序列属于契约。
- 两端 glob 语义须一致；跑 `GitActions` 需补 `updateCachedStatus`、`isAllInitialized`、`tools.hasTooBigFiles`、`displayMessage`。
- `isomorphicGitPushAfterMerge.test.ts` 是补丁回归开关，升级 `isomorphic-git` 前不可放宽对象数断言。

## 5. 什么时候需要下钻

- 改两端后端 / merge / status：读 `simpleGit.test.ts`、`isomorphicGit.test.ts` 及 `gitManager.test.ts`。
- 改拉取恢复、冲突救援、手动解决或远端分支清理：读 `pullRecovery.test.ts` 与 `phoneSync.test.ts`；弱网重试读 `networkPolicy.test.ts`；askpass 读 `askpass.test.ts`。
- 监督器测试在 `tests/syncSupervisor.test.ts`；fixture 见 `tests/helpers/.frac.md`。
