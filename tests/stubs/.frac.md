# .frac.md — tests/stubs

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

只有 `obsidian.ts`：`obsidian` 包在 Node/Vitest 下的手写最小替身，由 `vitest.config.ts` 的别名接管源码里所有 `import ... from "obsidian"`；提供最小类与函数骨架，不模拟完整桌面运行环境。

## 2. 直属文件

- `obsidian.ts`：
  - 值与类：`moment`、`Platform`、`Notice`（含 `messageEl`）、`TFile` / `TFolder`、`Plugin` 等，以及最小界面/设置基类（`Modal`、`SuggestModal`、`FuzzySuggestModal`、`Setting`、`ItemView` 等）。
  - 函数：`normalizePath`（归一化斜杠并剥除首尾斜杠，与真实 Obsidian 一致，保障 `MyAdapter.readdir`）、`debounce`、`requestUrl`、`setIcon` / `setTooltip`、`getLanguage`。

## 3. 子目录导航

无直属子目录。

## 4. 本层约束 / 约定 / 禁忌

- `Platform` 默认桌面值；测移动端须自行修改并在清理时还原。`requestUrl` 默认返回空 404，按需在用例覆写。
- `debounce` 不启定时器，只靠 `.run()` 手动触发；`Notice` 记录文本和超时。
- `Modal` / `ItemView` 等替身类仅提供最小字段或空方法：测完整视图或 DOM 交互需按需提供最小元素替身或走端到端；`TFile` / `TFolder` 依赖 `tests/setup.ts`。
- 类型刻意保持最小，只够别名编译；源码新引用未覆盖的 Obsidian API 时，只按需补充最小定义（不引入真实 `obsidian` 包）。

## 5. 什么时候需要下钻

- 源码新增 `obsidian` 导入或 stub 行为不匹配真实客户端：先读本文件，再决定补 `obsidian.ts` 或在用例局部覆写。
- 伪造 plugin / vault：见 `tests/helpers/.frac.md`。
