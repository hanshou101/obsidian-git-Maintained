# .frac.md — tests/setting

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

`src/setting/` 的单元测试，只有一个文件，测维护版接手官方 Git 插件（id `obsidian-git`）的逻辑：`StockPlugin` 与 `LocalStorageSettings.importFrom`。不经 Obsidian，不碰 git。

## 2. 直属文件

- `stockPlugin.test.ts`：文件内的 `createPlugin(vault)` 造最小假插件：`manifest.id`（默认 `git-maintained`）、`configDir` 与内存文件表的 `adapter`、`app.plugins.enabledPlugins`（`hasPluginsApi: false` 时整个 `app.plugins` 为 `undefined`）、内存 Map 的 localStorage、`vi.fn()` 的 `log`，再挂上真的 `LocalStorageSettings`。覆盖：
  - `isEnabled()`：官方插件在 `enabledPlugins` 里为真；没有私有 API `app.plugins` 时为假；自己的 id 就是 `obsidian-git`（按官方 id 构建）时也为假，且 `importSettings()` 返回 `null`。
  - `importSettings()`：返回官方 `data.json` 的内容（路径跟着 `configDir` 走），并把 `username`、`gitPath`、`envVars`、`lastAutoPull` 从 `obsidian-git:` 前缀抄到 `git-maintained:`；自己已有的值不覆盖，`pluginDisabled`、`pausedAutomatics` 不抄。
  - 没有 `data.json`、内容不是对象（`[]`、`null`、`1`）或不是合法 JSON：返回 `null` 且不抄；不是合法 JSON 时另经 `plugin.log` 记一条读取失败。

## 3. 子目录导航

无直属子目录。

## 4. 本层约束 / 约定 / 禁忌

- 这里不用 `tests/helpers/createFakePlugin`：它没有 vault adapter、`app.plugins` 和 localStorage 读写，而这几样正是被测对象要用的。
- `src/main.ts` 在 Vitest 里 import 不进来（它连带的类继承了 `tests/stubs/obsidian.ts` 没有定义的 Obsidian 类，本文件对它只做 type import）。所以 `onload` 里的拦截与 `loadSettings` 里的接手没有单元测试，要在真实 Obsidian 里验；这里只测它们调用的 `StockPlugin`。

## 5. 什么时候需要下钻

- 改接手的范围（抄哪些键、读哪个文件、什么算「官方插件已启用」）：先改 `src/setting/stockPlugin.ts` 或 `localStorageSettings.ts`，再改这里的期望；说明见 `src/setting/.frac.md`，设计背景见 `MAINTENANCE.md`。
