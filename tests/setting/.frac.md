## 1. 本目录是什么

`src/setting/` 的单元测试。目前只有一个文件，测维护版接手官方 Git 插件（id `obsidian-git`）的逻辑：`StockPlugin` 与 `LocalStorageSettings.importFrom`。不经 Obsidian，不碰 git。

## 2. 直属文件

- `stockPlugin.test.ts`：文件内的 `createPlugin(vault)` 造一个最小的假插件：`manifest.id`（默认 `git-maintained`）、`app.vault.configDir` 与 `adapter.exists / read`（内存里的文件表）、`app.plugins.enabledPlugins`（`hasPluginsApi: false` 时整个 `app.plugins` 是 `undefined`）、`app.loadLocalStorage / saveLocalStorage`（内存 Map）、`log`（`vi.fn()`），再挂上真的 `LocalStorageSettings`。用例：
  - `isEnabled()`：`enabledPlugins` 含 `obsidian-git` 为真，不含为假；没有私有 API `app.plugins` 时为假。
  - 自己的 id 就是 `obsidian-git` 时（按官方 id 构建），`isEnabled()` 为假，`importSettings()` 返回 `null`。
  - `importSettings()` 返回官方 `data.json` 的内容（用 `configDir` `.obsidian-phone` 验证路径跟着 `configDir` 走），并把 `obsidian-git:` 前缀的 `username`、`gitPath`、`envVars`、`lastAutoPull` 抄到 `git-maintained:`；自己已有的值（`hostname`）不覆盖；`pluginDisabled`、`pausedAutomatics` 不抄。
  - 没有官方 `data.json`：返回 `null`，localStorage 一个键也不抄。
  - `data.json` 是 `[]`、`null`、`1`：返回 `null`、不抄；不是合法 JSON（`{`）：同样不抄，另经 `plugin.log` 记一条 `Could not read …`，带 `SyntaxError`。
