# .frac.md — docs/assets

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

纯图片目录（PNG 与 GIF），没有文本、代码或脚本。沿用上游文档的配图，供上级 `docs/` 的 Markdown 页面按文件名嵌入：`line-author-*` 给 `Line Authoring.md`，两张 Git for Windows 安装向导截图给 `Installation.md`。

## 2. 直属文件

- **Git for Windows 安装向导截图**：`credential-manager-windows-git.png`（选 Git Credential Manager 的一步）、`third-party-windows-git.png`（PATH 选项里选 “Git from the command line and also from 3rd-party software” 的一步）。
- **Line Authoring（行作者标注）演示图**，文件名统一前缀 `line-author-`，下面按演示的设置分组，只写去掉前缀后的名字：
  - 入口与默认外观：`activate.png`、`default.png`、`dark-light.gif`（深浅色主题）、`quick-configure-gutter.gif`（在 gutter 上快速配置）。
  - 颜色与文字：`color-config.png`、`text-color.png`、`text-color-muted.png`、`text-color-normal.png`。
  - 提交信息：`commit-hash-full-name.png`、`commit-hash-full-name-config.png`、`copy-commit-hash.png`。
  - 日期格式：`custom-dates.png`、`custom-dates-config.png`、`natural-language-dates.png`。
  - 时区：`tz-config.png`，以及三种显示结果 `tz-author-local.png`（作者本地）、`tz-utc0000.png`（UTC）、`tz-viewer-plus0100.png`（查看者时区）。
  - 追踪行的来源（follow）：`follow-config.png`、`follow-all-commits.png`、`follow-no-follow.png`。
  - 忽略空白：`ignore-whitespace-before.png`、`ignore-whitespace-ignored.png`、`ignore-whitespace-preserved.png`（原文 / 忽略后 / 保留后）。
  - 其他行为：`untracked.png`（未提交的新行显示 `+++`）、`multi-line-newest.gif`（多行块只显示一个跨行的 gutter 单元）、`soft-unintrusive-ux.gif` 与 `soft-unintrusive-ux-editing.gif`（编辑时 gutter 不打扰输入）。

## 3. 子目录导航

无直属子目录。

## 4. 本层约束 / 约定 / 禁忌

- 页面按文件名引用图片：重命名、删除或移动文件前，先同步改 `docs/` 下 Markdown 里的引用，否则发布站点上的图会失效。`Installation.md` 用 Obsidian 嵌入（按文件名解析），`Line Authoring.md` 用相对路径 `assets/…`，移动本目录会破坏后者。
- 截图对应 Line Authoring 的设置项与界面，设置名或界面改版后可能过时。本目录没有源文件或生成脚本，只能重新截图并覆盖同名文件（文件名不变就不用改页面）。
- 仓库根目录的 `images/` 是另一个独立的图片目录，不要混放。

## 5. 什么时候需要下钻

- 改 Line Authoring 或 Windows 认证相关的文档页面时，先到 `docs/.frac.md` 找到引用这些图的页面，再回到这里确认文件名；除非要核对截图是否与当前界面一致，否则不用打开图片。
