## 1. 本目录是什么

纯图片目录：30 个文件（25 个 PNG、5 个 GIF），没有任何文本或代码。它们是供上游用户文档 `docs/` 的 Markdown 页面嵌入的截图与动图，通过文件名被引用。哪个页面用了哪些图，见上级 `docs/.frac.md`。
文件只有两大类：Line Authoring（行作者标注）功能的演示图，以及 Windows 上安装 Git 的向导截图。

## 2. 直属文件

- Git for Windows 安装向导截图（2 张 PNG）：
  - `credential-manager-windows-git.png`："Choose a credential helper" 一步，选中 Git Credential Manager。
  - `third-party-windows-git.png`："Adjusting your PATH environment" 一步，选中 "Git from the command line and also from 3rd-party software"（推荐项）。
- Line Authoring 演示图（28 个文件，文件名统一前缀 `line-author-`，按演示的设置分组）：
  - 入口与默认外观：`activate.png`、`default.png`、`dark-light.gif`（深浅色主题）、`quick-configure-gutter.gif`（在 gutter 上快速配置）。
  - 颜色与文字：`color-config.png`、`text-color.png`、`text-color-muted.png`、`text-color-normal.png`。
  - 提交信息：`commit-hash-full-name.png`、`commit-hash-full-name-config.png`、`copy-commit-hash.png`。
  - 日期格式：`custom-dates.png`、`custom-dates-config.png`、`natural-language-dates.png`。
  - 时区：`tz-config.png`，以及三种显示结果 `tz-author-local.png`（作者本地时区）、`tz-utc0000.png`（UTC+0000）、`tz-viewer-plus0100.png`（查看者时区，示例为 +0100）。
  - 追踪行的来源（follow）：`follow-config.png`、`follow-all-commits.png`（all commits：移动/粘贴后仍归因到最早观察到的提交）、`follow-no-follow.png`（不追踪）。
  - 忽略空白：`ignore-whitespace-before.png`、`ignore-whitespace-ignored.png`、`ignore-whitespace-preserved.png`（修改前 / 忽略后 / 保留后的对比）。
  - 其他行为：`untracked.png`（未提交的新行显示 `+++`）、`multi-line-newest.gif`（多行块如表格只显示一个跨行的 gutter 单元，取最新提交）、`soft-unintrusive-ux.gif`、`soft-unintrusive-ux-editing.gif`（编辑时 gutter 不打扰输入）。

无直属子目录。

## 4. 本层约束 / 约定 / 禁忌

- 页面按文件名引用图片：重命名、删除或移动文件前，要同步改 `docs/` 下 Markdown 页面里的引用，否则发布站点上的图片会失效。
- `line-author-*` 的图对应 Line Authoring 的设置项；设置名或界面文案改版时，这些截图可能已过时。本目录里没有源文件或生成脚本，只能重新截图后覆盖同名文件（保持文件名不变就不用改页面）。
- 仓库根目录的 `images/` 是另一个独立的图片目录，不要和这里混放。

## 5. 什么时候需要下钻

- 改 Line Authoring 或 Windows 认证相关的文档页面时，先到 `docs/.frac.md` 找到引用这些图的页面，再回到这里确认文件名；本目录不需要读取图片内容，除非要核对截图是否与当前界面一致。
